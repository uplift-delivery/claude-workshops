This is a hand-built GTFS feed small enough to read by eye. It is deliberately seeded with defects to serve as a teaching fixture: stops at impossible coordinates (Null Island), trips with impossibly fast hops, service coverage windows that don't align with the feed window, and low-contrast colors. These defects are intentional and must not be "fixed." See [../ANSWER-KEY.md](../ANSWER-KEY.md) for details on each trap and how to identify it.
